# 配对模型的事件预警互补性

Notebook 36，使用现有模型预测，不重新训练。585 ZIP、2020年9月1日至12月28日预报日期、1,131个可评价事件。保留原事件定义和校准阈值。

## 主要发现
- DP + RF OR：检出率80.46%，正确预警比例66.09%。相对RF多检出13个事件，但多194次误报。检出率提高1.15个百分点，正确比例下降10.58个百分点。
- DP + RF AND：检出率77.45%，正确预警比例79.56%。相对RF少检出21个事件，少48次误报。正确比例提高2.90个百分点。
- XGBoost + RF AND：检出率72.68%，正确预警比例84.39%。相对XGBoost少检出3个事件，少9次误报。正确比例提高0.72个百分点，检出率下降0.27个百分点。
- 没有配对组合在两个指标上同时超过它的两个成员。互补信息存在，但实际组合的提升有限，而且有取舍。差异尚未做统计显著性检验。

## 看哪些文件
1. pair_warning_metrics.csv：三个单独模型和六种组合的指标。
2. pair_vs_members.csv：每种组合分别对照两个成员，变化单位为百分点，同时记录新增检出与原来检出现在漏掉的事件。
3. individual_event_rescue.csv：原始单独模型中，一个漏掉的事件被另一个抓住的比例。这是事后覆盖分析，不等于组合预警指标。
4. pair_detection_precision.png：检出率和预警正确比例对比。

OR/AND在同一个ZIP、同一个预报日期的原始预警信号上组合，然后重新应用统一7天冷却期与一对一事件匹配。不能直接把已匹配事件取并集。预警规则、模型与事件定义未改变；只比较2020年探索性验证，不使用2021—2023年。

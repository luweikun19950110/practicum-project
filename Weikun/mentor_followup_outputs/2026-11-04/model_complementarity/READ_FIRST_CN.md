# 先看哪些结果

这是2020年探索性验证分析，不是新的未使用测试集。

1. warning_vote_metrics.csv：核心表。逐个模型与至少1、2、3个模型同意的事件检出率、预警正确比例、误报数量、提前时间。
2. event_overlap_counts.csv：原来三个独立模型共同检出/漏掉的事件。不是新的投票模型得分。
3. direction_overlap_by_actual_class.csv：对上升、下降、精确平稳分别看互补性。
4. direction_vote_rules.csv：方向投票的召回与精确率。至少一个模型正确不代表能够事先选出它，也不代表总体准确率。
5. figures：direction_overlap.png 和 warning_vote_comparison.png 可用于汇报。

发现：OR投票提高检出率但增加误报；AND投票提高预警正确比例但漏掉更多事件；两票同意是中间方案，尚未确定哪种最优。不根据这段评估结果重新调整阈值。模型共享输入且高度相关，三票不能当成三份独立证据。

三模型都漏掉153/1131次事件。748次三个独立预警系统都检出、137次两个检出、93次只有一个检出。重新按每日投票应用冷却和匹配后，结果会不同。
